# bsdmod — BSD Kernel Driver (Planned)

Placeholder for the FreeBSD/OpenBSD/DragonFly BSD kernel driver for the Cavium CN6640 SNIC10E.

## Status

**Work in progress - does NOT compile yet.** `if_octnic.c`, `if_octnic.h` and the `Makefile` are an
early skeleton generated by a local multi-model agent setup (2026-11-05). It reuses the register
layout of `linuxmod/octnic.c` (BAR2 offsets, ring size, phase bits), but it is not a working driver:
at the time of this commit `make` fails on FreeBSD 14.5 with 4 errors (`IFQ_PREPEND` does not exist,
`IF_DEQUEUE`/`IFQ_*` used with the wrong signature/header, an undeclared `_kernel` identifier) and the
datapath (RX DMA with busdma, TX, reset/hang handling, sysctl temperature) is not implemented. Nothing
here has been loaded on a real card.

What is missing: a driver that compiles and loads, a card simulation test, `install.sh` support for
FreeBSD, a CI workflow (`build-freebsd.yml`) and a release asset. Treat this branch as a starting point,
not as a release.

## Planned Architecture

The BSD driver will follow the same shared-memory BAR2 datapath as Linux and Windows:

```
HOST (BSD)                      PCIe                        CARD (OpenWrt from RAM)
┌────────────────┐                               ┌───────────────────────────┐
| octnic.ko      |   BAR2 window (64 MiB)        | octshm_card (card kmod)   |
| if_octnic      │◄───── shared-memory rings ────►│  per-port rings           │
| oct0 / oct1    │                               │  DPI RX engine            │
└────────────────┘                               └─────────────┬─────────────┘
```

## Implementation Plan

### Phase 1: Framework (Future)
- [ ] if_octnic.c — BSD network interface driver
- [ ] Uses `bus_space` API for BAR2 memory access
- [ ] Integrates with FreeBSD netif or OpenBSD ifnet
- [ ] mbuf-based packet handling (BSD equivalent of sk_buff/NetBuffer)

### Phase 2: Features (Future)
- [ ] Multi-queue support (BSD SMP scalability)
- [ ] DMA mode support (card→host DPI)
- [ ] Zero-copy TX (same as Linux ztx=1)
- [ ] HWMON integration (sysctl for temps)

### Key BSD API Differences from Linux

| Concept | Linux | FreeBSD/BSD |
|---------|-------|-------------|
| Network driver | net_device_ops | ifnet + if_drv |
| Packet buffer | sk_buff | mbuf / mbuf cluster |
| Memory mapping | ioremap_wc() | bus_space_map() |
| Kernel threads | kthread_run() | kthread_create() / taskqueue |
| PCI access | pci_read_config_* | bus_read_*() |
| Module params | module_param() | SYSCTL_NODE() |

### Cross-Platform Abstractions Needed

To share code between Linux, Windows, and BSD:

```c
// os_abstraction.h (planned)
typedef void* os_mem_t;
os_mem_t os_map_bar(int bar_idx, size_t size);
void os_unmap_bar(os_mem_t mapping);
u32 os_read32(os_mem_t base, u32 offset);
void os_write32(os_mem_t base, u32 offset, u32 val);
// ... etc
```

## Building (When Available)

### FreeBSD
```bash
cd bsdmod
make kernel
sudo kldload octnic.ko
ifconfig oct0 up
```

### OpenBSD
```bash
cd bsdmod
make
sudo modload octnic.so
ifconfig oct0 up
```
